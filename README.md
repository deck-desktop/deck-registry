# Deck plugin registry

The registry [Deck](https://deck.hasan-zarif.com) reads to list, install and update plugins and
language definitions. Deck and the website fetch it from

```
https://raw.githubusercontent.com/deck-desktop/deck-registry/main/catalog.json
```

(Deck 1.6 and older read `index.json` beside it.)

## What is here

| | |
|---|---|
| `packages/<kind>/<id>.json` | The record: who owns each package (by GitHub id) and every version ever published, with its files' SHA-256 and what its manifest said. Only this is edited. |
| `catalog.json` | The list, read whole: each package's newest version, without its files. |
| `details/<kind>/<id>/<version>.json` | One per version: its files (GitHub release downloads), their hashes, its README. Never changes once published. |
| `index.json` | The older format, files inline, for Decks before 1.7.0: the newest version each of those can run. |
| `tools/build-registry.mjs` | Builds the three above from `packages/`. |

`catalog.json`, `details/` and `index.json` are generated by `.github/workflows/build.yml` on
every push to `main` that changes `packages/`, so they are never edited by hand.

A package's files are the assets of its GitHub release (`v<version>`) in its own repository. Deck
downloads them from there and checks each one against the hash recorded here before installing
anything.

## Checks

```sh
node tools/build-registry.check.mjs
```
